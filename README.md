# Mosquito Revenge

A 2D top-down stealth arcade game built using Go and Ebitengine v2. All visuals are generated at runtime using geometry/vectors; no image files are required.

## Features

- 360 x 640 portrait logical canvas.
- Menus, gameplay, game-over screen, session-best scores, a blood meter, and an "itch" meter.
- A mosquito whose abdomen enlarges and turns red while feeding on blood.
- Swatting hands that include a warning phase, providing a window of time to escape.
- Fans that generate a constant gust of wind.
- Android touch (drag/hold) and an on-screen "DASH" button; PC controls include WASD/arrow keys, Space, Shift, or the left mouse button.
- Build targets: desktop, WebAssembly, and Android APK.

## Running on Desktop

Requirements: Go 1.25 or later.

```sh
go mod tidy
go run .
```

## Running the WebAssembly Version Locally

```sh
go run github.com/hajimehoshi/wasmserve@latest .
```

Open the local URL displayed by `wasmserve` in your terminal. For GitHub Pages deployment, the workflow file `.github/workflows/build.yml` builds the WASM version and deploys it to Pages whenever code is pushed to the `main` or `master` branch. Ensure that **Settings → Pages → Build and deployment → GitHub Actions** is enabled in your repository.

## Building for Android Locally

Requirements: Go 1.25+, JDK 17, Android SDK, Android NDK 27.2.12479018, and Gradle 8.11.1. From the project root directory:

```sh
mkdir -p mobile/android/app/libs
go run github.com/hajimehoshi/ebiten/v2/cmd/ebitenmobile bind \
  -target android \
  -androidapi 23 \
  -javapkg com.example.mosquitorevenge \
  -o mobile/android/app/libs/mosquitorevenge.aar \
  ./mobile

gradle --no-daemon -p mobile/android assembleDebug
```

The debug APK can be found at `mobile/android/app/build/outputs/apk/debug/app-debug.apk`. The AAR is generated by `ebitenmobile bind`, and Gradle then packages the AAR—along with the Android Activity—into an APK.

## CI/CD

The workflow automatically builds two artifacts:

- `mosquito-revenge-android-debug`: The debug APK can be downloaded from the **Actions → workflow run → Artifacts** tab.
- GitHub Pages: The browser version is automatically published upon pushing to the `main` or `master` branch, provided that GitHub Pages is configured to use GitHub Actions.

The debug APK is not signed for a Play Store release. For a production release, add a keystore and signing configuration as GitHub Actions Secrets.
